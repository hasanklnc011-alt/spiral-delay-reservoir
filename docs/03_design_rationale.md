# Design rationale

| Component | Role | Reason | Source | Status |
|---|---|---|---|---|
| Coherent delay spiral | Creates time-separated features | Explicit delay provides a controllable temporal basis | Project P6 record | Simulation-derived; physical route partly assessed |
| 20 tap markers | Identifies delay samples | Supports the stated 19-lag/20-tap architecture | Project P6 record | Implemented in Blender; not a layout proof |
| EO routing | Selects receiver features | Encodes the 10 PD × 3 slot system concept | Project P6 record | Conceptual; required high-speed evidence open |
| Combiner and PD/TIA blocks | Interference and detection | Produces modeled coherent/quadratic readout features | [@donati2024] | Conceptual; component validation open |
| MRR motivation | Nonlinear/resonant photonic mechanism | Supports recurrent-photonics research context | [@bazzanella2022; @gironcastro2024] | Literature-supported |

The Blender colour and placement choices are presentation choices only. They do not encode measured material stacks, dimensions, loss, coupling, or fabrication rules.
