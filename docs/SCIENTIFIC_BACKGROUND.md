# Scientific background

Reservoir computing uses nonlinear transformations and fading memory to make temporal tasks accessible to a trained linear readout. In photonic implementations, the relevant source of memory may be a delay loop, resonator dynamics, carrier or thermal dynamics, or a combination; these mechanisms must not be conflated [@donati2024; @bazzanella2022].

Microring resonators are useful because resonance and nonlinear detuning can shape optical signals. Silicon-specific free-carrier and thermo-optic mechanisms are not assumed to transfer directly to the project's SiN/Kerr-oriented reasoning [@gironcastro2024]. Coherent interference and photodetection provide the quadratic temporal features used in the system model.

The project therefore treats a recurrent architecture as scientifically plausible, while keeping physical component acceptance separate from computational benchmark performance. A continuous-time RNN based on programmable photonic weight banks is a distinct architecture, not evidence that this project has demonstrated one [@tait2017].
