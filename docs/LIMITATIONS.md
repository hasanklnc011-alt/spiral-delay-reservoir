# Limitations

- The Blender model is a conceptual presentation model, not a fabrication-oriented GDS layout.
- The exact association between the active Blender session used for the render and the copied `mcp.blend` file is unverified.
- P5 is a system simulation, not an experimental photonic demonstration.
- P6 physical acceptance remains incomplete; approved splitter/combiner S-parameters, propagation-loss evidence, selector bandwidth, PD/TIA linearity, and thermal validation are not all available.
- Large raw HDF5 solver outputs are intentionally excluded from this Git repository. Their paths are recorded in the source snapshot manifest; reproducibility from those binaries is therefore partial.
- No new simulations, blind re-evaluations, or Blender geometry edits were performed during archival.
