# results/

This folder is a **pointer**, not a data store.

- **Human-readable results:** [`../docs/RESULTS_SUMMARY.md`](../docs/RESULTS_SUMMARY.md)
  (full P1–P6 table with SHA-256 provenance) and each phase's `RESULTS.md`.
- **Structured per-phase records:** `p1-coherent-delay/runs/`, …,
  `p5-publication/runs/`, `p6-physical-validation/runs/` (JSON, hash-locked).
- **Raw solver outputs:** `p6-physical-validation/runs/*.hdf5` — 59 FDTD /
  mode-solve files tracked with **Git LFS** (`git lfs pull` to fetch).
- **Figures:** [`../docs/figures/`](../docs/figures/), regenerated by
  `scripts/make_figures.py`.

Canonical vs. intermediate result files are identified in each phase's
`runs/README.md`.
